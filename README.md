# MosquitoOverkill

A small **game jam project** made around the theme **"OVERKILL"**.

The idea is simple:

> There are mosquitoes.
> They keep multiplying.
> You have increasingly ridiculous weapons.
> Eventually, you use a nuke.

This project is intentionally silly and pretty different from my usual game-dev focus. I normally make darker, horror-focused games, but this was a fun excuse to make something dumb and chaotic for a jam.
